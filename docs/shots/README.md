# Снимки окон Winbox 4 из CI

Эти файлы создаёт workflow `.github/workflows/winbox-shots.yml` — на настоящем
RouterOS, без рисунков и макетов:

1. ставятся QEMU, Xvfb, tesseract, xdotool, ImageMagick;
2. скачивается CHR RouterOS 7.24.6 и запускается в QEMU (`-cpu max`, диск `if=ide`,
   проброс порта 8291 на 127.0.0.1);
3. поднимается Xvfb 1600×1100 и запускается настоящий Winbox 4.4;
4. `.github/scripts/winbox-nav.py` входит в роутер и открывает окна по списку;
5. `.github/scripts/winbox-capture.sh` (режим `nav`) делает вход и снимок стола;
6. всё складывается в артефакт `winbox-shots` и коммитится в ветку
   (`CI: настоящие скриншоты Winbox 4 [skip ci]`).

## Как открываются окна

Координаты «пункт дерева y=+105» не масштабируются и не знают про подменю,
поэтому окно ищется по названию:

* `winbox-nav.py` делает снимок экрана, распознаёт текст (tesseract) в области
  дерева или содержимого и щёлкает по найденному месту;
* список того, что снимать, лежит в `.github/scripts/shot-list.txt` —
  `имя|путь в меню|new|путь в приложении`;
* подменю и вкладки проходятся так же: после клика по разделу ищется название
  подпункта (`IP → Firewall → NAT`), для диалогов находится кнопка `New`;
* кадр сохраняется только если окно реально открылось — проверяется разброс
  яркости области содержимого, пустой серый стол не снимается.

## Что важно знать про вход

* Порт 8291 у QEMU открывается сразу при старте, поэтому «порт отвечает»
  ничего не значит: RouterOS грузится 8–15 минут. Признак готовности —
  появление дерева меню на экране.
* В Xvfb нет оконного менеджера: `xdotool windowactivate` падает, и ввод
  текста уходит «в никуда». Поэтому основной способ входа — двойной щелчок
  по строке роутера во вкладке **Neighbors** (там CHR виден по MAC
  `52:54:00:12:34:56`); ввод адреса в `Connect to` — резервный.
* Перед каждым окном жмём Escape трижды, а каждые 14 окон Winbox
  перезапускается: иначе на экране копятся диалоги и клики по дереву
  перестают доходить.

## Связь с приложением

```
node scripts/win4-import.js
```

Копирует кадры из `docs/shots/jpg/` в `app/src/main/assets/www/img/shots/`,
собирает галерею `js/data/win4.js` и привязку «шаг статьи → снимок»
`js/data/photos.js`. Подписи к кадрам — `scripts/win4-titles.js`.

Если окно есть в `img/shots`, но статьи про него нет (например, Mesh),
импорт его пропускает: ui-check требует, чтобы каждый файл где-то
использовался, а выдавать одно окно за другое нельзя.
